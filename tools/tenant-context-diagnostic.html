Tenant Context সংযোগ পরীক্ষা

এই পৃষ্ঠা শুধু বর্তমান লগইন সেশন দিয়ে tenant-context Edge Function পরীক্ষা করে। কোনো Branch, Farmer, Collection বা Settings ডেটা পরিবর্তন করে না।

পরীক্ষা শুরু হয়নি।

পরীক্ষা চালাতে উপরের বোতাম চাপুন।

নিরাপত্তা: এখানে Password, OTP, JWT বা API Secret চাওয়া হয় না। কোনো Token বা User ID স্ক্রিনে দেখানো হয় না। এই পরীক্ষা সফল হলেও ব্যবসায়িক Write Permission তৈরি হয় না। একই Browser Profile ও একই ওয়েব ঠিকানায় আগে TEST 2 অ্যাপে লগইন থাকতে হবে।
