# Bangladesh address reference data

This compact file is derived from **iqbalhasandev/bangladesh-geo-json**:
https://github.com/iqbalhasandev/bangladesh-geo-json

It supplies the offline cascading picker used by the Farmer form:
8 divisions, 64 districts, 495 upazilas, unions and pourashavas.
Names retain both Bangla and English forms. The upstream dataset is licensed
under the MIT License. Copyright (c) 2026 Iqbal Hasan.

The upstream source is community-maintained; verify local spelling and
administrative changes before relying on it for official records.
